# Instructions for AI

## Before working

Read, in this order:

1. `projects/<slug>/PROJECT_CONTEXT.md`
2. `projects/<slug>/CURRENT_STATE.md`
3. `projects/<slug>/DECISIONS.md`
4. `projects/<slug>/TODO.md`

Treat newer decisions as authoritative over older chat history.

## After significant work

Update only what changed:

- CURRENT_STATE — actual current state.
- DECISIONS — long-term decisions.
- TODO — remaining work.
- CHANGELOG — important completed changes.

## Never store

- passwords
- API keys
- access tokens
- Supabase service-role keys
- private credentials
- unnecessary full chat transcripts

## Handoff format

A useful handoff records:

- what was done
- what was not done
- files changed
- known problems
- next step
