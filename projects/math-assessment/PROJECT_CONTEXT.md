# Project Context — Math Assessment / Quizizz-Wayground

## Purpose

**Math Assessment / Quizizz-Wayground** is a separate educational assessment-content project for generating and maintaining mathematics question banks and import-ready assessment materials.

It is distinct from School Gradebook / Class Journal, Tutor Schedule and School Attendance.

## Historical requirements

Prior work described:
- Excel import formats for Quizizz/Wayground;
- large question banks, including 100 and 1000 tasks;
- random selection of a subset for each student;
- mobile participation;
- automatic grading;
- five answer choices per question;
- plausible distractors tied to common misconceptions;
- rational-number addition/subtraction questions;
- practical-content word problems requiring construction of mathematical expressions;
- balanced categories: geometric, physical, quantitative, financial, work and household/domestic.

## Platform scope

Quizizz and Wayground are historical platform targets. The current platform-specific import schema must be verified before generating a new production file.
