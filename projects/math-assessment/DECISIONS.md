# Decisions — Math Assessment / Quizizz-Wayground

## 2026-09-27 — Separate project boundary

**Decision:** Math Assessment / Quizizz-Wayground is an independent project record in AI_CONTEXT_HUB.

**Reason:** Its main deliverable is an assessment-content/question-bank workflow, with its own generation, import and validation requirements.

## 2026-09-27 — Preserve broad assessment scope

The project covers both:
- standard mathematics question banks, including rational-number tasks;
- practical-content word problems focused on constructing mathematical expressions.

## 2026-09-27 — Verification rule

Historical Excel layouts, platform behavior and prior task counts are not treated as current production facts until verified against current source files or platform documentation/configuration.

## Content-quality rule

Distractors should be plausible and tied to common mathematical misconceptions when the assessment design calls for them. The correct answer must remain unambiguous.
