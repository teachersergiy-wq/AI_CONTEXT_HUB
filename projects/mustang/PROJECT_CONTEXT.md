# Mustang — PROJECT_CONTEXT

## Goal

Develop the Mustang game with the horse, elephants, difficulty levels, records/rating and AI. The project includes desktop work and a planned mobile browser version.

## Main technologies

Current project code is Python; browser/mobile work is a separate future implementation.

## Key rules

- Do not replace working game logic without checking the current repository first.
- Important gameplay decisions must be recorded here and in DECISIONS.md.
- Keep record/rating rules explicit and reproducible.

## Known requirements

- Levels are based on elephant count.
- Record comparison uses elephants, moves and time.
- Moves must have much greater weight than time.
- AI improvement includes learning from played games.
- User games and world-record games should remain available for analysis where applicable.
- Save/pause/undo behavior has explicit gameplay rules.
- A mobile web version is planned.
