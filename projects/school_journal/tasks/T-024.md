Enough fictional data to make `v_lesson_window` return rows, so the app can be developed and tested.

## Required
- A separate, idempotent file `supabase/seed_demo.sql` (not part of the migrations).
- It finds the owner with `select id from public.profiles where role = 'owner' limit 1`. No UUID or email is written into the repository.
- Content: one journal (for example Algebra, 8-А), 5 lessons, lesson records for the 10 students covering all characteristics (absence `н`, homework in three states, notebook, textbook, not taking notes, board refusal, late minutes, exits with reasons, several behaviour marks), a few assessments of kinds `current`, `thematic` and `board`.
- A cleanup script `supabase/seed_demo_cleanup.sql` that removes exactly the demo data, so real data can be added later without leftovers.
