# T-008 — Safeguards for the public repository

- **Owner:** Owner
- **Status:** PLANNED
- **Depends on:** none

## Goal
Reduce the risk that comes with a public repository.

## Steps (check that each option is available on the free plan)
1. Turn on GitHub secret scanning and push protection for `school_journal`.
2. Protect `main`: require a pull request, forbid force pushes. This enforces the rule that nobody pushes straight to `main`.
3. Ask the AIs to start every commit message with a tag such as `[grok]`, `[chatgpt]` or `[codex]`, because all commits come from the owner's account.

## Rules that stay in force
No real student data, no service-role key, no passwords in the repository or the Hub.

## Done when
Owner confirms; recorded in `CURRENT_STATE.md`.
