# T-007 — Disable public signup in Supabase Auth

- **Owner:** Owner
- **Priority:** P0
- **Status:** PLANNED
- **Depends on:** none

## Goal
Make sure nobody except the owner can ever have an account in this project.

## Steps (dashboard)
1. Authentication → Providers / Settings: disable public sign-ups.
2. No self-registration on a school system.

## Done when
New users cannot self-register. Only the owner account exists (or accounts the owner creates manually).
