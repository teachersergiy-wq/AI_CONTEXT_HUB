# T-007 — Disable public signup in Supabase Auth

- **Owner:** Owner
- **Priority:** P0
- **Status:** PLANNED
- **Depends on:** none

## Goal
Make sure nobody except the owner can ever have an account.

## Steps
1. In the Supabase dashboard of project `school_journal`, open the Authentication settings and turn off the option that allows new users to sign up. Keep the existing owner account.
2. Tell Claude when it is done. Claude cannot see the Auth settings and records the answer as the owner's statement, not as VERIFIED.

## Why
The "single user" decision is only safe while nobody else can register. Until T-023A is applied, a registered user could change their own role to owner.

## Done when
Owner confirms; recorded in `CURRENT_STATE.md`.
