# T-007 — Disable public signup in Supabase Auth

- **Owner:** Owner
- **Priority:** P0
- **Status:** PLANNED
- **Depends on:** none

## Goal
Make sure nobody except the owner can ever have an account in this project.

## Steps (dashboard)
1. Authentication → Providers → Email: disable "Enable sign ups" if present, or restrict as needed.
2. Authentication → Settings: disable public sign-ups / enable "Confirm email" as appropriate for single-user.
3. Do not leave open registration on a school system.

## Done when
New users cannot self-register. Only the owner account exists (or accounts the owner creates manually).
