- **Owner:** Claude proposes, Owner decides
- **Status:** PLANNED

## Goal
Choose how the PWA is hosted at no cost, and how to deal with the Supabase Free auto-pause.

## To compare (verify current free-plan terms first)
- Hosting: GitHub Pages (may be free only for public repositories on a free GitHub plan), Cloudflare Pages, Netlify, Vercel.
- Auto-pause: a scheduled keep-alive request (for example a scheduled GitHub Actions workflow), or accepting a manual resume after holidays.
