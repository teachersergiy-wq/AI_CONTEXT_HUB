# School WebApp — PROJECT_CONTEXT

## Goal

Build a mobile-first web application for school attendance, meals and related reporting with a centralized database.

## Architecture

- Mobile-first web UI
- Supabase PostgreSQL
- Authentication and role-based access
- Server-side logic through Supabase Edge Functions when needed

## Main data

- students
- teachers
- classes
- schedule
- permissions
- attendance
- meals
- academic records
- grades
- reports

## Key rules

- Attendance is retained across school days.
- Reporting must support day, class, month, year and student views.
- The system records who submitted information and when.
- The interface is designed for phone use with large controls.
